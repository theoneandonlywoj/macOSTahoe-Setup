# herdr Cheatsheet

Prefix: **Ctrl+B** (4-tier keyboard scheme, tier = modifier on top of the prefix)

## Core

| Action | Keys |
| --- | --- |
| Help | `prefix+?` |
| Settings | `prefix+s` |
| Detach | `prefix+q` |
| Reload config | `prefix+shift+u` |
| Goto | `prefix+g` |
| Workspace picker | `prefix+w` |
| Toggle sidebar | `prefix+b` |
| Copy mode | `prefix+ctrl+y` |
| Resize mode | `prefix+ctrl+e` |
| Edit scrollback | `prefix+e` |
| Cycle pane next | `prefix+tab` |
| Cycle pane previous | `prefix+shift+tab` |

## Workspaces (shift)

| Action | Keys |
| --- | --- |
| New workspace | `prefix+shift+n` |
| Rename workspace | `prefix+shift+r` |
| Close workspace | `prefix+shift+x` |
| Previous workspace | `prefix+shift+h` |
| Next workspace | `prefix+shift+l` |
| Switch workspace | `prefix+shift+1..9` |

## Tabs (bare)

| Action | Keys |
| --- | --- |
| New tab | `prefix+c` |
| Next tab | `prefix+]` |
| Previous tab | `prefix+[` |
| Switch tab | `prefix+1..9` |
| Rename tab | `prefix+r` |
| Close tab | `prefix+x` |

## Agents (ctrl)

| Action | Keys |
| --- | --- |
| Previous agent | `prefix+ctrl+[` |
| Next agent | `prefix+ctrl+]` |
| Focus agent | `prefix+ctrl+1..9` |
| Open notification target | `prefix+ctrl+o` |

## Panes (ctrl)

| Action | Keys |
| --- | --- |
| Focus pane left | `prefix+ctrl+h` |
| Focus pane down | `prefix+ctrl+j` |
| Focus pane up | `prefix+ctrl+k` |
| Focus pane right | `prefix+ctrl+l` |
| Swap pane left | `prefix+ctrl+shift+h` |
| Swap pane down | `prefix+ctrl+shift+j` |
| Swap pane up | `prefix+ctrl+shift+k` |
| Swap pane right | `prefix+ctrl+shift+l` |
| Split vertical | `prefix+ctrl+v` |
| Split horizontal | `prefix+ctrl+minus` |
| Zoom | `prefix+ctrl+z` |
| Close pane | `prefix+ctrl+x` |
| Rename pane | `prefix+ctrl+r` |
| Last pane | `prefix+ctrl+shift+[` |

## Notes

- Worktree keys (`new_worktree`, `open_worktree`, `remove_worktree`) are intentionally unset.
- `remote_image_paste` keeps its built-in `ctrl+v` default (remote-only).
